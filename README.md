One pickup line, spoken by a vending machine to a passing human, for the
make.fun contest "One Line, One Minute: The Vending Machine Pickup Line Contest".

## Run

Requires Node 22 or later. From any directory:

```sh
node main.ts
```

It writes exactly one line to `/output/entry.txt`.
